## 🌟 Funkciók

- **Mém böngésző:** Végtelen görgetés, kategóriák szerinti szűrés (tanárok, tantárgyak, iskolai események).
- **Feltöltési rendszer:** Képek, GIF-ek és szöveges mémek egyszerű feltöltése.
- **Értékelés és interakció:** Kedvelések (Upvote/Downvote), hozzászólások és megosztási lehetőségek.
- **Felhasználói profilok:** Saját feltöltések követése, egyedi profilképek.
- **Adminisztrációs felület:** Moderációs rendszer a nemkívánatos vagy sértő tartalmak szűrésére, jelentések kezelése.

A projekt a modern webfejlesztési trendeknek megfelelően készült. Az alábbi technológiák találhatók meg a rendszerben:

- **Frontend:** HTML5, TypeScript
- **Backend:** Node.js
- **Adatbázis:** MySQL
- **Stílusok/UI:** Tailwind CSS
